# Folder Structure — Security Vault

```
00 Inbox/                        Unprocessed capture: quick notes, links, IOCs, mid-flow
01 Daily/                        Daily work logs (YYYY-MM-DD.md), written by the nightly task
02 Meetings/                     One file per meeting — summary, decisions, action items
02 Meetings/_Companies/          Context files for external companies / vendors
02 Meetings/_Recurring/          Running-log notes for recurring 1:1s and syncs
02 Meetings/Transcripts/         Verbatim transcripts (skipped by default in search)
03 People/                       One file per person you work with
04 Teams/                        One file per internal team you partner with
05 Investigations/               Security investigations
05 Investigations/Fraud/         Vendor/BEC fraud triage, known fingerprints
05 Investigations/Threats/       Threat intel, actor TTPs, IOCs
05 Investigations/Pentest/       Pentest scans, red-team findings, vuln remediation
06 Programs/                     Your security programs — canonical program state
07 Resources/                    Runbooks, tool docs, references, playbooks
08 Templates/                    Reusable note templates
09 Tasks/                        Live task list, auto-maintained by the nightly task
10 Coach/                        Weekly security-career coaching reports
Context/                         Evergreen notes: who you are, goals, org context
```
